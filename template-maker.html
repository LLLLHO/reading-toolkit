「静态文字」怎么写？点开看说明

1. 它是什么：元素类型选「静态文字」，输入框里写什么就原样印出来 —— 只有花括号里的字段名会被换成真实内容。位置由它所在的槽（左/中/右）决定，不用填坐标。

2. 能插的字段（花括号 + 名字，名字照抄）：

{bookName}书名 {chapterTitle}章节名 {pageIndex}当前页码 {pageCount}本章总页数 {page}页码/总页数，如 3/12 {progress}进度 % {chapterProgress}本章进度 % {time}时间 {battery}电量，如 87%

3. 举几个例子：第 {pageIndex} 页 / 共 {pageCount} 页　{chapterTitle} · {time}　— 未完 —　{bookName}｜{progress}%。
不带花括号的一律当普通文字，标点、竖线、符号、emoji 都行（连续多个空格会被浏览器合并成一个）。

4. 最容易写错的四处：① 括号必须是半角 { }，中文全角 ｛ ｝ 不认；② 名字区分大小写，{PageIndex} 无效；③ 名字只能是英文字母，{页码} 不认；④ 花括号和名字之间不能有空格，{ pageIndex } 不认。
判断方法很简单：预览里如果原样显示出「{pageIndex}」这几个字，就是没认出来。

5. 只想要固定文字：那就一个字段都别插，直接写「※※※」「未完待续」「—— 卷一 完 ——」这类内容，它就是个纯文字标签。内容清空这条元素就不显示；只想首页出现，把「显示于」设成「仅首页」。

6. 和「动态字段」的区别：动态字段只能单独输出一个值（下拉里选一个）；静态文字能把这个值夹在固定文字中间 —— 想显示「第 3 页」而不是孤零零一个「3」，就用静态文字。

7. 不用背字段名了：点一下静态文字的输入框，下面会弹出书名 / 章节名 / 时间 / 电量 / 当前页码 / 总页数 / 页码总页数 / 进度 / 本章进度 这些中文标签， 点一个就插到光标处（例如先点「书名」和「电量」，再补上自己的字，就成了 当前在读{bookName}，电量还剩{battery}）。页眉页脚的静态文字里也能这样点。

首字是怎么做出来的？点开看

1. 只取每章第一个字：导出模板里的 JS 会在每次排版前，找到本章第一个有内容的段落，把它的第一个字包进 span.s-cap；＊※· 这类分隔行会被跳过，不会被当成开头。

2. 为什么不用 ::first-letter：它会把行首的引号、标点并到后面那个字上，结果套出来的是一小片空白。所以改成手动包一层。

3. 底色透明：首字只是放大/换色，不占固定格子；后面的文字会自然绕在它右边。想让它占两三行，把字号调到 3 倍以上就行。

4. 图片首字：图垫在字的后面（相框类图请用「字压在图上」），也可以选「只留图」把字藏起来，纯用花字图代替首字。

标题这些样式是怎么画的？点开看

1. 全部纯 CSS：竖条/方块/细线/双线/短横线用伪元素画，徽标是 ::before 里的一段文字。不依赖图片，换颜色只改一个值。

2. 强调色管什么：线条、色块、徽标底色都用「强调色」；留空就用标题自己的颜色。标题文字色与强调色可以不同（比如深红字 + 浅红细线）。

3. 徽标文字：只有「徽标+细线」这个样式会用到，写 CHAPTER、ANTE 8、第 1 卷 都行，太长会撑宽，建议不超过 10 个字。

4. 字号是倍数：1.35 就是正文的 1.35 倍，跟着 App 字号一起缩放；想写死 px 就去导出的 CSS 里改。

文字

「对齐」决定文字靠哪边，「挪动」在这一步之后再平移一段——想把标题摆在偏左三分、或者压到分隔线上方，直接用这两个值挪，不用改代码。

颜色

同步移动：开着时拖其中一页，另一页实时跟着走（两页共用一个位置）；关掉后拖哪页只改哪页，另一页停原处、会记成「两页位置不同」，想合回一处点「对齐两页」。想让两页各摆不同位置又可以随便拖，就点每条的「拆」把它拆成首页/续页两份。
文字装饰怎么写？点开看说明

1. 能加几条：点「＋ 文字装饰」可一直加，每条独立定位。两条 left/top 一样就会叠在一起（后加的在上），想加阴影/描边效果就叠两层。

2. 文本里能插的动态字段（用花括号包住，名字大小写要和下面完全一致）：

{bookName}书名 {chapterTitle}章节名 {pageIndex}当前页码 {pageCount}总页数 {page}页码/总页数，如 3/12 {progress}全书进度 % {chapterProgress}本章进度 % {time}时间 {battery}电量，如 87%

不认识的普通文字原样显示，所以 — 第 {pageIndex} 页 —、※※※、章节编号、分隔符、署名、版权年份都能直接写。

3. 位置：left / top 是相对整页的百分比（左上角是 0,0）。左 6、上 92 就是左下角附近。太长会自己折行：不给「宽」时宽度跟着文字走， 最多撑到页面右边剩的地方，所以「我记得我在读《书名》」这种长句不会戳出屏幕；想固定每行多宽就填「宽」。

4. 显示范围：都显示 / 仅夜间 / 仅日间。放一整套「夜里才露出的花纹」选仅夜间；只想白天出现的记号（比如日间版的页码框）选仅日间。

5. 样式：字 = 字号 px；色 = 颜色，点↺ 正文色清空后跟随正文颜色（日间夜间自动切）；宽 = 这条文字的宽度百分比（留空＝自动）；对齐 = 折行后靠左/中/右；转 = 旋转；透 = 透明度（0 全透明，1 不透明）。

5.1 字号和每行字数怎么调最快：开「🖐 在预览里拖动」后，这条文字上会出现 8 个把手—— 左右两边的只改宽度（每行放几个字，字数变了自己折行）、上下两边的只改字号、 四角的两个一起改，想怎么配就怎么拖；松手后自动记下来（宽会换算成百分比存进配置）。

6. 想加图片：不用这里，把图拖到上面的虚线框（装饰图）。角标、花纹、贴纸都走这条路，多一个「宽」= 宽度占页面百分比，高度按原图比例自动。

7. 快捷摆位：点「🖐 在预览里拖动」，直接拖右侧预览里的装饰，松手自动写回 left/top，比手填快。

进度条 SVG 怎么用？点开看说明

1. 什么样的能导：整段 <svg …>…</svg> 的进度条/刻度尺，拓展名是 .svg 或 .txt 都行。能跟着翻页走的写法有三种，导入时自动识别：

{= chapterPct * 3.6 }算式写法（Lovia、Reeden 常见） {chapterPct}直接写变量名（Reeden 工坊） data-progress="chapter"配 clipPath 的「生长/填充」写法

三种都不带的，就当一张静态矢量图导进来，也能用，只是不会动。

2. 为什么它本来用不了：这些写法都不是阅读的模板语法，直接粘进页面 HTML 只会变成非法属性值，整条线不画。导入时会把算式翻译成普通 JS 函数（不依赖 eval），把 clipPath 的裁剪宽度翻译成按进度缩放，再挂到每页排版时执行一次。

3. 能认的变量
进度类（全部取同一个数 = 本章进度 0–100）：chapterPct、chapterProgress、chapterPercent、progress、percent、pct、bookPct、bookPercent
页码类：pageIndex（当前页，从 1 起）、pageCount / total（本章页数）、page（如 3/12，是文字，别拿去算数）
函数只认 min / max / abs / round / floor / ceil / pow / sqrt。出现别的名字会拒绝导入并提示是哪个变量。
说明：模板里拿不到「全书页数」，所以 bookPct / bookPercent 也退化成本章进度。

4. w / h / em 怎么处理：这几个是画布宽高和字号（Reeden 的「可自调宽高」就是它）。导入时直接换成具体数字写死 —— viewBox="0 0 {w} {h}" 会变成 0 0 1072 96。因为成品是靠「宽 %」整块缩放的，写死设计尺寸后比例反而不会走样；想改大小，用列表里的「宽」就行。

5. 走动原理：进度 = 本页序号 ÷ 本章页数。第 1 页几乎空、最后一页满。它跟着当前这一章走，不是全书进度 —— 这也是这类「轨迹/刻度」进度条原本的语义。

6. 改色：这类图都是用 currentColor 画的，所以列表里的日间色 / 夜间色直接决定整条的颜色；两格都留空 = 跟随正文颜色（推荐，日夜自动跟着变）。

7. 大小与位置：「宽」是占页面宽度的百分比，高度按原图比例自动；左/上同样按百分比。翻页看效果：点预览上的 ◀ ▶，它会一页一页往前走。

8. 压到正文了：勾着「文字下层」时它垫在正文后面（当暗纹用，不挡字）；想要它浮在字上面就取消这个勾。也可以把「宽」调小、或把它挪到页脚下面的空白处。

9. 自己能做：reeden-tools.github.io/svg-studio 是别人做的 Reeden 进度条工坊，选样式 → 选变化方式 → 调颜色，复制生成的 SVG 存成 .txt 就能拖进来。它用的 {= w / 2 }、{chapterPct} 这套写法本工具都能读。
